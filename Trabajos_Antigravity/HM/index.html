Metaanálisis & Estadística

Metodología y Motores de Cálculo de MetaAnalysis Pro

Esta aplicación utiliza un sistema de doble motor para garantizar fluidez en la entrada de datos y máximo rigor científico en los resultados finales.

1. Motor Estándar (Cálculo en Tiempo Real)

  • Tecnología: JavaScript nativo (Frontend).
  • Uso: Proporciona una vista previa rápida de los tamaños de efecto (Hedges' g, SMD) y varianzas a medida que se introducen los datos.
  • Método: Utiliza el método clásico de la varianza inversa y el estimador estándar de DerSimonian-Laird (DL) para modelos de efectos aleatorios. Es útil para exploración inicial, pero tiene limitaciones con muestras pequeñas.

2. Motor Avanzado (R Engine)

  • Tecnología: Lenguaje R y la librería profesional metafor (Backend).
  • Uso: Ejecuta el análisis estadístico definitivo, con calidad para publicación científica.
  • Métodos específicos utilizados:
    • Efecto Global: Función rma.uni(). Por defecto, utiliza el método REML (Restricted Maximum Likelihood), el estándar actual para estimar la varianza entre estudios (τ²).
    • Heterogeneidad: Calcula el intervalo de predicción y compara 7 estimadores distintos (REML, DL, PM, EB, ML, SJ, HE) para evaluar la robustez de I².
    • Sesgo de Publicación: Test de Egger (regtest()), Test de Begg (ranktest()), y análisis Trim-and-Fill (trimfill()) con estimadores robustos para evitar falsos positivos.
    • Análisis de Subgrupos: Evaluado como moderador categórico derivando el test ómnibus (Qbetween) para diferencias significativas.
