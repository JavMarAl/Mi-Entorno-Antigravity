# Development Workflow Bundle

## Overview

Consolidated workflow for end-to-end software development covering web, mobile, and backend development. Orchestrates skills for building production-ready applications from scaffolding to deployment.

## Workflow Phases

### Phase 1: Project Setup
- **Skills**: `app-builder`, `senior-fullstack`, `environment-setup-guide`, `concise-planning`
- **Goal**: Scaffold project, select tech stack, and configure CI/CD.

### Phase 2: Frontend Development
- **Skills**: `frontend-developer`, `frontend-design`, `react-patterns`, `typescript-pro`, `tailwind-patterns`
- **Goal**: Component architecture, UI implementation, and responsive design.

### Phase 3: Backend Development
- **Skills**: `backend-architect`, `backend-dev-guidelines`, `nodejs-backend-patterns`, `fastapi-pro`, `auth-implementation-patterns`
- **Goal**: API design, database connection, and authentication.

### Phase 4: Database Development
- **Skills**: `database-architect`, `database-design`, `prisma-expert`, `postgresql`, `neon-postgres`
- **Goal**: Schema design, migrations, and query optimization.

### Phase 5: Testing
- **Skills**: `test-driven-development`, `javascript-testing-patterns`, `python-testing-patterns`, `playwright-skill`
- **Goal**: Unit, integration, and E2E testing reaching coverage targets.

### Phase 6: Code Quality
- **Skills**: `code-reviewer`, `clean-code`, `lint-and-validate`, `security-scanning-security-sast`
- **Goal**: Linters, code review, and security scans.

### Phase 7: Deployment
- **Skills**: `deployment-engineer`, `docker-expert`, `vercel-deployment`, `github-actions-templates`
- **Goal**: Containerization, build pipelines, and production deployment.

## Quality Gates
- [ ] All tests passing
- [ ] Code review completed
- [ ] Security scan passed
- [ ] Documentation updated
