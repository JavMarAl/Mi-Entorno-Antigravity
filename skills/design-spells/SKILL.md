# Design Spells Skill

[Design Spells](https://www.designspells.com/) is a collection of exceptional design details—micro-interactions, easter eggs, and clever UX patterns—that transform standard interfaces into memorable digital experiences.

## Use this skill when

- Polishing a finished feature to actively add a "wow" factor.
- Designing unique interactions to replace standard web behaviors (e.g., clever hover states, creative loaders, surprising transitions).
- Implementing "Easter Eggs" or personality-driven design choices.

## Execution Workflow

1. **Identify Opportunity**: Target "boring" parts (submit buttons, profile photos, toggles).
2. **Research Spells**: Browse patterns like "magnetic hover", "physics-based interactions", or "fluid scroll".
3. **Adapt Pattern**: Fit the interaction to the brand seamlessly.
4. **Implement**: Use CSS, Anime.js, or Framer Motion for 60fps+ performance.

## Strict Rules

- **ABSOLUTE MANDATE**: Inject "magic" into standard components. DO NOT build in common ways.
- **Delight, Don't Distract**: The detail must be additive, not a barrier.
- **Quality Execution**: Ensure GPU-accelerated, silky-smooth performance. No layout shifts.
