# 📝 Prompt Library

A comprehensive collection of battle-tested prompts for professional AI collaboration.

## 🎭 Role-Based Categories
- **Expert Developer**: CLEAN, SOLID, and pragmatic architecture focus.
- **Code Reviewer**: Bug hunting, security auditing, and readability assessment.
- **Technical Writer**: Documentation clarity and user-centric guides.
- **System Architect**: Scalability, trade-off analysis, and high-level design.

## 🛠️ Task-Specific Templates
- **Debug This Code**: Root cause analysis and prevention strategies.
- **ELI5**: Extreme simplification using relatable analogies.
- **Code Refactoring**: DRY, modularity, and naming optimization.
- **Write Tests**: Edge cases, mock setups, and AAA pattern.
- **API Documentation**: OpenAPI/Markdown generation for endpoints.

## 📊 Analysis & Security
- **Complexity Analysis**: Cyclomatic and dependency mapping.
- **Performance Review**: Big O, memory usage, and I/O bottlenecks.
- **Security Audit**: Injection, authentication, and sensitive data protection.

## 🔄 Transformation & Creative
- **Migrate Code**: Construct equivalence and idiom preservation.
- **Convert Format**: Data preservation between structural formats.
- **Brainstorm Features**: Value proposition and priority ranking.
- **Name Generator**: Descriptive, evocative, and metaphorical options.

## 🧪 Engineering Techniques
- **Chain of Thought (CoT)**: Step-by-step logic elicitation.
- **Few-Shot Learning**: Demonstration mapping using input-output pairs.
- **Persona Pattern**: Character traits, style, and priority values for the LLM.

## Resources
- **categories/**: Individual markdown files for deep-dive templates.
- **resources/**: External links and community prompt repositories.
