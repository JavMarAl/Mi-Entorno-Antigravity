# Database Workflow Bundle

## Overview

Comprehensive database workflow for database design, development, optimization, migrations, and data engineering. Covers SQL, NoSQL, and modern data platforms.

## Workflow Phases

### Phase 1: Database Design
- **Skills**: `database-architect`, `database-design`, `postgresql`, `nosql-expert`
- **Goal**: Schema design, indexing strategy, and scalability planning.

### Phase 2: Implementation
- **Skills**: `prisma-expert`, `database-migrations-sql-migrations`, `neon-postgres`
- **Goal**: ORM configuration, migration creation, and model implementation.

### Phase 3: Query Optimization
- **Skills**: `database-optimizer`, `sql-optimization-patterns`, `postgres-best-practices`
- **Goal**: Execution plan analysis, index optimization, and caching.

### Phase 4: Data Migration
- **Skills**: `database-migration`, `framework-migration-code-migrate`
- **Goal**: Zero-downtime strategies, script testing, and data integrity.

### Phase 5: Pipelines & ETL
- **Skills**: `data-engineer`, `data-engineering-data-pipeline`, `airflow-dag-patterns`
- **Goal**: Ingestion design, transformations, and scheduling.

### Phase 6: Data Quality
- **Skills**: `data-quality-frameworks`, `data-engineering-data-driven-feature`
- **Goal**: Validation rules, quality metrics, and monitoring.

### Phase 7: Operations (DBA)
- **Skills**: `database-admin`, `backup-automation`
- **Goal**: Backups, replication, capacity planning, and security.

## Technology Stacks
- **PostgreSQL**: `postgresql`, `postgres-best-practices`, `neon-postgres`, `prisma-expert`
- **MongoDB**: `nosql-expert`, `azure-cosmos-db-py`
- **Redis**: `bullmq-specialist`, `upstash-qstash`
- **Warehousing**: `clickhouse-io`, `dbt-transformation-patterns`

## Quality Gates
- [ ] Schema designed and reviewed
- [ ] Migrations tested in staging
- [ ] Performance benchmarks met
- [ ] Monitoring and backups in place
